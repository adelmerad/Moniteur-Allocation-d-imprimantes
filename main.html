Procédure Demander(K, type)
  si (Dispo < K) alors
    switch(type):
      case système: enfiler(FilSys, K-Dispo); Dispo=0; syst.wait;
      case utilisateur: enfiler(FilUsr, K); user.wait;
  sinon Dispo = Dispo - K;
  fsi;

Procédure Libérer(m)
  Étape 0Dispo = Dispo + m;
  tantque(syst.empty==faux et Dispo >= Tête(FilSys)) faire
    Étape 1Dispo -= Tête(FilSys); Défiler(FilSys); syst.signal;
  fait
  si(syst.empty==faux) alors
    Étape 2Tête(FilSys) = Tête(FilSys) - Dispo; Dispo = 0;
  fsi;
  tantque(User.empty==faux et Dispo >= Tête(FilUsr)) faire
    Étape 3Dispo -= Tête(FilUsr); Défiler(FilUsr); user.signal;
  fait
Garde de sécurité : Libérer(m) est refusé si m dépasse le nombre d'imprimantes réellement occupées, ce qui garantit l'invariant 0 ≤ Dispo ≤ N.
